Pertanyaan yang Sering Diajukan

Bagaimana cara klaim bonus Free VPS Linux 1 bulan? ▼

Kredensial IP, SSH root, dan akses VPS Linux langsung diberikan pada hari pertama kelas Jago Hermes. VPS aktif penuh selama 30 hari untuk keperluan deployment agent mandiri.

Apakah saya harus punya laptop berspesifikasi GPU tinggi? ▼

Tidak perlu. Untuk kelas Self-Hosted LLM dan Agent, peserta menggunakan instance server lab yang disediakan. Laptop standar RAM 8GB sudah sangat cukup.

Bagaimana jika saya berhalangan hadir saat sesi live? ▼

Setiap sesi direkam dalam kualitas HD dan langsung dibagikan ke portal peserta beserta seluruh source code dan repository lab pada malam yang sama. Akses rekaman berlaku seumur hidup.

Bahasa pemrograman apa yang digunakan? ▼

Kami menggunakan Python, Golang, dan Shell script untuk implementasi backend dan agents, serta n8n dan PostgreSQL/Supabase untuk pipeline integrasi. Peserta dengan dasar logika pemrograman sudah bisa mengikuti dengan lancar.
