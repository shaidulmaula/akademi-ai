# Kognitif AI Lab // Akademi AI Platform

Platform penjualan kelas & workshop praktisi AI Engineering (Jago Hermes, Autonomous Agents, Local LLMs, n8n Automations, dan Production RAG).

## Architecture
- **Language:** Go (`net/http`, `html/template`, `//go:embed`)
- **Database:** Pure-Go SQLite (`modernc.org/sqlite`, CGO-free, WAL mode)
- **Styling:** Tailwind CSS v4 Standalone CLI
- **Deployment:** Docker / Coolify / Linux systemd
- **Notifications:** Telegram Bot API (`@notifonezbot`)
